# ANSHCODEX LABS Website

Static first-version marketing website for ANSHCODEX LABS.

## Files
- index.html — main website
- styles.css — responsive styling / brand system
- script.js — navigation, animations and demo quote form

## Run locally
Open index.html in a browser, or serve the folder with any static server.

## Before publishing
1. Connect the quote form to your email/Google Sheet/Supabase/CRM.
2. Replace demo portfolio cards with real projects.
3. Add final Instagram, email, WhatsApp and domain links.
4. Add a privacy policy and terms page.
5. Add analytics after deployment.

## Suggested hosting
Vercel, Netlify or GitHub Pages for the static version.
